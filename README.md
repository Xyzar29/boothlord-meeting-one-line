## The line

> The answer is yes, the deadline is Friday, and this sentence is the meeting — everyone can go home now.

One sentence. It gives the decision, the deadline, and the dismissal, so
after it there is nothing left for the meeting to do.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (103 characters, one sentence).
